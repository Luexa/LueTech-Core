# LueTech

Core mod for the pack LueTech LE (LTLE) on Minecraft **1.21**.

Disclaimer: As this mod is purely intended for use in LTLE, we have chosen to make various content mods required dependencies and/or apply mixins to them unconditionally.
Use this mod outside of LTLE at your own risk.
